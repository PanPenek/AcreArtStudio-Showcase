Prompt queue

Build from image references

Have a picture you want more of? Add it here and the writer works from it. Three ways in, and they know different amounts: a file is pixels only, so the vision model reads it — subject, wardrobe, lighting, camera, palette, rendering style. A card from the library still carries the prompt that made it. And a post already up on DeviantArt is looked up in the prompt archive, so a deviation from a year ago whose card was deleted can still hand the writer the exact words that produced it — which is the case worth having when something goes unexpectedly well. References are read once and kept for the session; changing the mode or the count re-writes without re-reading.

Build from a story

Describe a story in your own words — who it is about, what happens to them, where it ends up. The app reads it into characters and key moments, then writes real generator prompts from it, in your own prompt style: Scene by scene turns it into an in-order sequence, The strongest moment stages the single best scene several ways, and Pictures from this story writes standalone posts set inside it. The story is read once and kept — change the mode or the count and re-write without paying for the read again.
